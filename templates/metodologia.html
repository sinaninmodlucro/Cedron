Metodología e historial

Cedron describe el contexto de cada metal con cinco indicadores públicos y comprobables. Ningún método predice precios con fiabilidad: el objetivo es ser transparente, constante y verificable. Los análisis los firma {{ sitio.autor }}.

Los indicadores

Cada indicador suma +1 (favorable), 0 (neutral) o −1 (desfavorable). Si un indicador no tiene datos, no cuenta. La lectura es favorable con +{{ i.lectura.favorable_desde }} o más, desfavorable con {{ i.lectura.desfavorable_hasta }} o menos y neutral en medio. Con menos de tres indicadores disponibles no se publica lectura.

Cómo se seleccionan las noticias

Cada titular recibe una nota de 0 a 100: relevancia temática ({{ cfg.noticias.pesos.relevancia }} %), calidad del medio ({{ cfg.noticias.pesos.calidad_medio }} %), actualidad ({{ cfg.noticias.pesos.actualidad }} %) y confirmación por otros medios ({{ cfg.noticias.pesos.confirmacion }} %). Se publican las que superan {{ cfg.noticias.umbral_publicacion }} puntos. Las noticias repetidas en varios medios se agrupan. Los medios que venden metales se marcan como «medio comercial» y no bastan por sí solos: su noticia debe estar confirmada por otro medio.

Cambios en la metodología

Si se añade, cambia o elimina una regla, se anunciará aquí con fecha y motivo. Las lecturas anteriores no se recalculan.
